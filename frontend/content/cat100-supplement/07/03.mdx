# Template-Based Productivity

![Template-Based Productivity textbook visual](/course-art/deep-exemplars/cat100-supplement/07-03-template-based-productivity.png)

## Why This Section Matters

A template is the difference between doing a task once and doing it once for every future time. The student who retypes a budget total every term, or hand-formats a weekly status note from scratch, is paying a tax that compounds. The student who builds the calculation as a formula and saves the blank shell as a reusable file pays the cost once. This section is about the mechanics that make a document reusable rather than disposable: live formulas instead of typed values, cell references that copy correctly, and a master file you never edit directly.

The skill matters most in spreadsheets, where the gap between a typed number and a formula is the gap between a document that goes stale the moment you change an input and one that stays correct forever. Understanding relative versus absolute references is the single highest-leverage spreadsheet idea a freshman can learn.

## Learning Targets

- Replace hand-typed totals with formulas (`=SUM`) so values recalculate when inputs change.
- Distinguish relative references (`B2`) from absolute references (`$C$1`) and predict how each behaves when copied.
- Keep a blank master template separate from each filled-in working copy.
- Justify a template by the recurring task it eliminates, not by how the document looks.

## Opening Case

A student builds a course-budget spreadsheet, types the total `250` into the bottom cell, and submits it. A week later the lab fee changes from \$45 to \$60. The student updates the lab-fee cell, but the total still reads `250`, because it was a typed number, not a formula. The spreadsheet now contradicts itself, and nobody notices until grading.

The lesson is that a typed value is a snapshot frozen at the moment you typed it, while a formula is a living relationship that updates with its inputs. Every recurring document should be built from living relationships.

## Core Concept

Template-based productivity rests on two mechanics.

The first is the **formula**: a cell whose value is computed from other cells rather than typed. `=SUM(B2:B4)` does not store a number; it stores an instruction to add the range, recomputed every time any cell in it changes. This is why a budget built with formulas can never go stale: the total is defined as "whatever the parts add up to," not "250."

The second is the **reference type**, which controls what happens when you copy a formula. This is the concept students most often get wrong:

| Reference | Written as | When copied down a column | Use it for |
| --- | --- | --- | --- |
| Relative | `B2` | Shifts to `B3`, `B4`, ... | The value on each row |
| Absolute | `$C$1` | Stays locked at `C1` | A shared constant like a tax rate |
| Mixed | `$C1` or `C$1` | Locks only the part with `$` | Locking a column but not a row |

A formula like `=B2*$C$1` says "this row's cost times the one fixed tax rate." Copy it down and `B2` becomes `B3`, `B4` (each row's own cost) while `$C$1` stays pinned to the single rate cell. Get the dollar signs wrong and the formula either drifts off the rate or fails to advance through the rows.

The third practice is **separating master from working copy**: keep `budget_template.xlsx` blank and reusable, and Save As a dated copy (`budget_2026spring.xlsx`) before filling it in, so the template survives for next term.

## Worked Example

Here is a real spreadsheet template turned from a retyped document into a reusable one.

**Before (a copied report with a hand-typed total):**

```
       A            B
1  Item         Cost
2  Books        120
3  Lab fee      45
4  Software     85
5  TOTAL        250        <- typed by hand, now wrong after edits
```

If you change the lab fee to 60, cell B5 still says 250. The value is stale.

**After (fixed structure, formulas, and a locked rate):**

```
       A            B            C
1  Item         Cost         Tax rate: 0.08
2  Books        120          =B2*$C$1
3  Lab fee      60           =B3*$C$1
4  Software     85           =B4*$C$1
5  TOTAL        =SUM(B2:B4)   =SUM(C2:C4)
```

Three concrete moves made it a template:

1. **Formula instead of a typed total.** `=SUM(B2:B4)` recalculates the moment a cost changes.
2. **Relative and absolute references.** `=B2*$C$1` copies down so B shifts to B3, B4 while the tax rate stays locked at `$C$1`.
3. **Edit a copy, keep the master blank.** Save As `budget_2026spring.xlsx` so `budget_template.xlsx` stays reusable next term.

## Decision Rule

Before you type a number into a spreadsheet, ask whether it is an input or a result. Inputs (costs, the tax rate) get typed once; results (totals, taxes) get formulas. Before you copy a formula, ask which references should move and which should stay, and add `$` to the ones that must stay.

A reusable document passes three checks:

1. **Formula check:** Is every computed cell a formula, so nothing goes stale when an input changes?
2. **Reference check:** When you copy a formula, do row references shift and shared constants stay locked with `$`?
3. **Master check:** Is the blank template preserved separately from the filled-in working copy?

If a "total" is a typed number, the document is a one-time snapshot, not a template.

## Common Misreadings

The most damaging error is typing a result you could compute. A hand-typed total looks identical to a formula on screen but silently goes wrong the first time an input changes.

The second is forgetting the dollar signs. `=B2*C1` copied down becomes `=B3*C2`, `=B4*C3`, so the tax rate reference drifts off the rate cell entirely and produces garbage. Lock the constant with `$C$1`.

## Textbook Walkthrough

Apply this to a weekly grade tracker. You want a sheet where you enter points earned and points possible for each assignment, and a final cell shows your current percentage. Inputs are the two point columns, typed each week. The percentage is a result: `=SUM(B2:B10)/SUM(C2:C10)`, formatted as a percent. Because it is a formula, every new graded item you enter updates your standing automatically.

Now suppose each category has a weight (homework 30%, exams 70%) stored in a corner cell. Each category's weighted contribution is `=category_percent*$E$1` style, with the weight cell locked by `$` so it does not drift when you copy the formula across categories. Save the empty version as `grade_tracker_template.xlsx`; each course gets its own Save As copy. The walkthrough shows the same three mechanics (formula, locked reference, master copy) producing a tool you reuse for every class.

## What Strong Reading Looks Like

A strong reader clicks into a spreadsheet cell to see whether it holds a number or a formula, rather than trusting the displayed value. A total that turns out to be typed is a defect, however correct it looks today.

A strong reader of a template can answer four questions:

1. Which cells are inputs (typed) and which are results (formula-driven)?
2. When this formula is copied, which references move and which stay locked, and is that what the math requires?
3. If an input changes, does every dependent value update on its own?
4. Where is the blank master, separate from this filled-in copy?

## Stronger Artifact Standard

The artifact is a working template plus a short note on its formulas. It is strong when a reader can change any input and watch every result update correctly, and when the absolute references are placed exactly where a shared constant lives.

A useful note sounds like this: "I replaced the typed total with `=SUM(B2:B4)` and built the tax column as `=B2*$C$1` so it copies down without losing the rate. I rejected hard-coding the 0.08 rate into each formula because then changing the rate would mean editing every row instead of one cell."

## Transfer Case

Move the template to a context with a different constant, say a currency conversion instead of a tax rate. The structure is identical: per-row values stay relative, the conversion rate stays absolute in one cell. What changes is that exchange rates move daily, so the single locked cell now needs a date label and a habit of updating it. Recognizing that the `$`-locked-constant pattern transfers, while the maintenance discipline around the constant must adapt, shows real command of the idea.
