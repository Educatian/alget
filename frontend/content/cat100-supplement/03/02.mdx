    ## Transfer Move

    **CAT 100 context.** Formulas for Everyday Analysis belongs to **Data Storytelling With Excel**, where learners work on undergraduate digital fluency and AI-assisted productivity. The section uses a concrete artifact instead of a generic reflection prompt: **GitHub Pages file tree with accessibility, privacy, and publishing checks**.

    The section is designed so the learner can move the same judgment pattern to a new tool, audience, or classroom setting. Transfer is visible only when the learner names the constraint that changes across contexts.

    The learner's first task is to decide what the artifact claims. The claim must name an audience, a constraint, and a reason the artifact matters. For this section, the relevant constraints come from **NACE career readiness**, **ISTE digital citizenship**, and **data-ink and visual evidence**. A polished artifact that does not expose those constraints is not yet high-quality intelligent textbook evidence.

    Existing intelligent textbooks already offer adaptive pathways, embedded checks, or social annotation. This section must therefore do something more specific: it must connect a course artifact to adaptive support. Compared with a static textbook, the page asks for action. Compared with a generic quiz engine, it keeps the artifact trace. Compared with a social annotation tool, it can use the annotation type and quote location to select the next support action.

    ## Adaptive Support Rule

    ALGET should use the following decision rule for this section:

    - If the annotation is a **question**, offer a focused explanation tied to **NACE career readiness**.
    - If the annotation is **confusion**, offer a worked contrast between a weak and strong GitHub Pages file tree with accessibility, privacy, and publishing checks.
    - If the annotation is an **insight**, ask the learner to transfer the decision to a new audience.
    - If the annotation is a **connection**, ask for evidence that the connection changed the artifact.
